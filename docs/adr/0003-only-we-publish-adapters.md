# Only the owner publishes Adapters to the Marketplace

A user's agent may build and use an **Adapter** privately for its own **Company**. To be listed in the **Marketplace** it must pass the repeated test loop, then be reviewed and published by us. Adapters run in the server-side runner, never in the user's agent, and never see passwords. This avoids one bad or sloppy adapter mishandling other **Companies**' **Connections**, at the cost of a manual review step. Phoenix and Scottsdale are built by us.
