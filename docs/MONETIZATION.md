# Monetization (draft)
Free to start; get people hooked on brain and permits, then charge on usage.

**Free:** brain (capped notes and one ingest per source), rules (packs + 1 custom set), permits for supported cities, 1 seat.
**Paid levers (ideas):**
- Ingest credits: big imports (email history, texts, OCR of scanned docs) cost real tokens.
- Seats: more team members on the shared brain.
- New portal CLI builds: first build costs credits, then shared with everyone.
- Automations and alerts: inspection reminders, daily briefs, follow-up drafts.
- Premium rule packs and trade templates.
- Usage-based meter for heavy chat and tool calls, like the big harnesses do.
Open: cost model per tenant on a Hostinger VPS; whether to pass through model tokens.
